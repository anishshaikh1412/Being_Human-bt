# Being Human — Fashion Store

A responsive fashion e-commerce website inspired by the Being Human clothing storefront. The project contains multiple HTML pages for browsing categories and navigating shopping-related sections.

## Features
- Multiple pages for clothing and category browsing
- Shopping cart page
- Help and order-support page
- Bootstrap-based layout and styling
- Responsive layout elements

## Built With
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/anishshaikh1412/Being_Human-bt.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No build step is required for the static pages.

## Project Structure
- `index.html` — main storefront page
- `beinghuman.html` — additional storefront page
- `cart.html` — cart page
- `education.html`, `health.html` — category pages
- `help.html` — help/order support page

## Notes
This is a learning/portfolio project. Product availability, checkout, and other e-commerce flows may be illustrative rather than connected to a production backend.
